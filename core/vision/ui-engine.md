# SAGE VISION: UI-to-Code Engine

Welcome to the **Matrix UI-to-Code Engine**. This system allows you to convert visual designs (screenshots, Figma URLs, Lapa.ninja posts) directly into high-fidelity, standardized React/Next.js components.

## Workflow

1.  **Input**: Send an image, a description, or a link to a design.
2.  **Analysis**: I will analyze the layout, typography, and color palette using Gemini's visual capabilities.
3.  **Synthesis**: I will map these visual elements to the [Matrix Design Tokens](file:///g:/matrix/core/design-system/tokens.css).
4.  **Implementation**: I will generate the component code (Tailwind + CSS Variables) and save it as a template.
5.  **Registration**: New templates are added to the [Template Registry](file:///g:/matrix/core/templates/registry.json).

## How to use a Template

Each saved template will have a unique ID. You can request a template by name or ID, and I will provide the component implementation or integrate it directly into your app.

## Design Alignment Principles

- **Token First**: Always prioritize `var(--m-*)` variables over raw hex codes.
- **Glassmorphism**: Use the `.m-glass` class for immersive surfacing.
- **Responsive**: All templates must use the fluid typography and spacing scale.
- **Accessibility**: Ensure high contrast and touch target readiness (44px min).
