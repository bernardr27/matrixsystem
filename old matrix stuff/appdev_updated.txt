## 1. EXECUTIVE SUMMARY

### 1.1 App Overview

**Tech Repair Pro** is a comprehensive mobile application designed for tech repair businesses, combining customer service management, AI-powered diagnostics, inventory tracking, and payment processing. Built specifically for Bernard's multi-device repair expertise (smartphones, tablets, computers, appliances, gaming consoles).

### 1.2 Key Features

**Customer-Facing:**
- Device intake with camera photo documentation
- AI-powered device recognition & damage detection
- Real-time repair tracking with push notifications
- Digital authorization & e-signatures
- Secure payment processing
- Repair history & warranty management

**Technician-Facing:**
- AI diagnostic assistant with Gemini integration
- Digital work orders with photo attachments
- Inventory management with barcode scanning
- Knowledge base & repair guides
- Time tracking per repair
- Quality checklists

**Business Management:**
- Analytics dashboard (revenue, performance metrics)
- Customer relationship management (CRM)
- Multi-location support
- Employee performance tracking

### 1.3 Technology Stack

- **Language:** Kotlin 1.9.x
- **UI Framework:** Jetpack Compose Material 3
- **Architecture:** MVVM + Clean Architecture
- **AI/ML:** Gemini 2.5 Pro, ML Kit, TensorFlow Lite
- **Backend:** Firebase (Auth, Firestore, Storage, Functions)
- **Local Database:** Room
- **Networking:** Retrofit + OkHttp
- **Image Processing:** CameraX, Coil
- **Payment:** Stripe Android SDK
- **Background Tasks:** WorkManager
- **Dependency Injection:** Hilt

### 1.4 Development Timeline

- **Environment Setup:** 2-3 days
- **Core Features (MVP):** 4-6 weeks
- **AI Integration:** 2 weeks
- **Testing & QA:** 2 weeks
- **Deployment:** 1 week
- **Total:** 10-12 weeks

   - Allow Gemini to access codebase context

3. **Install Gemini CLI (Optional):**
```bash
# Install Gemini CLI for advanced agent mode
npm install -g @google-labs/gemini-cli

# Authenticate

### 3.1 Clean Architecture Layers

```
┌─────────────────────────────────────────────┐

                    ↕ (State & Events)
┌─────────────────────────────────────────────┐
│           DOMAIN LAYER (Business Logic)     │
│  ┌──────────────────────────────────────┐   │
│  │  Use Cases                            │   │
│  │  Business Models                      │   │
│  │  Repository Interfaces                │   │
│  └──────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
                    ↕ (Data Operations)
┌─────────────────────────────────────────────┐
│            DATA LAYER (Data Sources)        │
│  ┌──────────────────────────────────────┐   │
│  │  Repositories (Implementation)        │   │
│  │  Data Sources (Remote/Local)          │   │
│  │  Firebase / Room / API                │   │
│  └──────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

### 3.2 MVVM Pattern

```kotlin
// View (Composable)
@Composable
fun RepairListScreen(
    viewModel: RepairViewModel = hiltViewModel()
) {
    val uiState by viewModel.uiState.collectAsState()
    
    when (uiState) {
        is UiState.Loading -> LoadingIndicator()
        is UiState.Success -> RepairList(uiState.data)
        is UiState.Error -> ErrorMessage(uiState.message)
    }
}

// ViewModel
@HiltViewModel
class RepairViewModel @Inject constructor(
    private val getRepairsUseCase: GetRepairsUseCase
) : ViewModel() {
    
    private val _uiState = MutableStateFlow<UiState<List>>(UiState.Loading)
    val uiState: StateFlow<UiState<List>> = _uiState.asStateFlow()
    
    init {
        loadRepairs()
    }
    
    private fun loadRepairs() {
        viewModelScope.launch {
            getRepairsUseCase()
                .catch { e -> _uiState.value = UiState.Error(e.message) }
                .collect { repairs -> _uiState.value = UiState.Success(repairs) }
        }
    }
}

// Use Case
class GetRepairsUseCase @Inject constructor(
    private val repository: RepairRepository
) {
    operator fun invoke(): Flow<List> = repository.getRepairs()
}

// Repository
interface RepairRepository {
    fun getRepairs(): Flow<List>
}

class RepairRepositoryImpl @Inject constructor(
    private val remoteDataSource: FirestoreDataSource,
    private val localDataSource: RepairDao
) : RepairRepository {
    override fun getRepairs(): Flow<List> = flow {
        // Try local first
        val localRepairs = localDataSource.getAllRepairs().first()
        emit(localRepairs.map { it.toDomain() })
        
        // Then sync with remote
        val remoteRepairs = remoteDataSource.getRepairs()
        localDataSource.insertAll(remoteRepairs.map { it.toEntity() })
        emit(remoteRepairs)
    }
}
```

package com.techrepairpro.app.ai.gemini

import android.graphics.Bitmap
import com.google.ai.client.generativeai.GenerativeModel
import com.google.ai.client.generativeai.type.BlockThreshold
import com.google.ai.client.generativeai.type.HarmCategory
import com.google.ai.client.generativeai.type.SafetySetting
import com.google.ai.client.generativeai.type.content
import com.google.ai.client.generativeai.type.generationConfig
import com.techrepairpro.app.BuildConfig
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class GeminiClient @Inject constructor() {
    
    private val apiKey = BuildConfig.GEMINI_API_KEY
    
    // Vision model for image analysis
    private val visionModel = GenerativeModel(
        modelName = "gemini-1.5-pro-latest",
        apiKey = apiKey,
        generationConfig = generationConfig {
            temperature = 0.4f
            topK = 32
            topP = 1f
            maxOutputTokens = 4096
        },
        safetySettings = listOf(
            SafetySetting(HarmCategory.HARASSMENT, BlockThreshold.MEDIUM_AND_ABOVE),
            SafetySetting(HarmCategory.HATE_SPEECH, BlockThreshold.MEDIUM_AND_ABOVE),
            SafetySetting(HarmCategory.SEXUALLY_EXPLICIT, BlockThreshold.MEDIUM_AND_ABOVE),
            SafetySetting(HarmCategory.DANGEROUS_CONTENT, BlockThreshold.MEDIUM_AND_ABOVE),
        )
    )
    
    // Text model for conversational AI
    private val textModel = GenerativeModel(
        modelName = "gemini-1.5-flash-latest",
        apiKey = apiKey,
        generationConfig = generationConfig {
            temperature = 0.7f
            topK = 40
            topP = 0.95f
            maxOutputTokens = 2048
        }
    )
    
    /**
     * Analyze device image and extract information
     */
    suspend fun analyzeDeviceImage(
        image: Bitmap,
        prompt: String
    ): Result = withContext(Dispatchers.IO) {
        try {
            val response = visionModel.generateContent(
                content {
                    image(image)
                    text(prompt)
                }
            )
            Result.success(response.text ?: "No response generated")
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
    
    /**
     * Generate diagnostic suggestions
     */
    suspend fun generateDiagnostic(
        deviceInfo: String,
        userComplaint: String,
        symptoms: List
    ): Result = withContext(Dispatchers.IO) {
        try {
            val prompt = buildDiagnosticPrompt(deviceInfo, userComplaint, symptoms)
            val response = textModel.generateContent(prompt)
            Result.success(response.text ?: "Unable to generate diagnostic")
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
    
    /**
     * Chat-based troubleshooting assistant
     */
    suspend fun chat(message: String, context: String? = null): Result = 
        withContext(Dispatchers.IO) {
            try {
                val fullPrompt = if (context != null) {
                    "Context: $context\n\nUser: $message"
                } else {
                    message
                }
                val response = textModel.generateContent(fullPrompt)
                Result.success(response.text ?: "No response")
            } catch (e: Exception) {
                Result.failure(e)
            }
        }
    
    private fun buildDiagnosticPrompt(
        deviceInfo: String,
        complaint: String,
        symptoms: List
    ): String = """
        You are an expert tech repair technician with certifications in Samsung, Apple, Google, 
        and major appliance repair. Analyze the following case and provide diagnostic insights.
        
        DEVICE INFORMATION:
        $deviceInfo
        
        CUSTOMER COMPLAINT:
        $complaint
        
        OBSERVED SYMPTOMS:
        ${symptoms.joinToString("\n- ", prefix = "- ")}
        
        Please provide:
        1. TOP 3 MOST LIKELY ROOT CAUSES (ranked by probability)
        2. RECOMMENDED DIAGNOSTIC STEPS (in order of execution)
        3. REQUIRED PARTS (if applicable, with part numbers when possible)
        4. ESTIMATED REPAIR TIME (in minutes)
        5. REPAIR DIFFICULTY (Easy/Moderate/Difficult/Expert)
        6. SAFETY PRECAUTIONS (if device involves batteries, high voltage, etc.)
        7. ESTIMATED COST (parts + labor estimate in USD)
        
        Format your response as structured JSON for easy parsing.
    """.trimIndent()
}

```kotlin
package com.techrepairpro.app.ai.gemini

import android.graphics.Bitmap
import com.google.ai.client.generativeai.type.content
import com.techrepairpro.app.domain.model.DeviceInfo
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import kotlinx.serialization.Serializable
import kotlinx.serialization.json.Json
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class DeviceRecognizer @Inject constructor(
    private val geminiClient: GeminiClient
) {
    
    private val json = Json { ignoreUnknownKeys = true }
    
    suspend fun recognizeDevice(image: Bitmap): Result = 
        withContext(Dispatchers.IO) {
            val prompt = """
                Analyze this image and identify the electronic device or appliance shown.
                
                Provide information in the following JSON format:
                {
                  "brand": "manufacturer name (Apple, Samsung, Google, LG, etc.)",
                  "model": "exact model name (e.g., iPhone 14 Pro, Galaxy S23 Ultra)",
                  "deviceType": "smartphone|tablet|laptop|desktop|appliance|gaming_console|smartwatch|tv|other",
                  "detectedDamage": ["list", "of", "visible", "damage"],
                  "condition": "Excellent|Good|Fair|Poor",
                  "confidence": 0.95,
                  "estimatedValue": "${'}XXX",
                  "serialNumberVisible": true/false,
                  "additionalNotes": "any other relevant observations"
                }
                
                If multiple devices are visible, focus on the primary device in the foreground.
                Be as specific as possible with the model identification.
            """.trimIndent()
            
            try {
                val response = geminiClient.analyzeDeviceImage(image, prompt)
                response.fold(
                    onSuccess = { text ->
                        val cleanedJson = extractJson(text)
                        val result = json.decodeFromString(cleanedJson)
                        Result.success(result)
                    },
                    onFailure = { e -> Result.failure(e) }
                )
            } catch (e: Exception) {
                Result.failure(e)
            }
        }
    
    suspend fun detectDamage(image: Bitmap): Result<List> = 
        withContext(Dispatchers.IO) {
            val prompt = """
                Analyze this device image and identify ALL visible damage, defects, or wear.
                
                Return a JSON array of damage items:
                [
                  {
                    "damageType": "type of damage",
                    "severity": "Minor|Moderate|Severe",
                    "location": "where on the device",
                    "description": "detailed description",
                    "repairability": "Easy|Moderate|Difficult|Not Repairable",
                    "estimatedCost": "${'}XX-${'}XX range"
                  }
                ]
                
                Common damage types:
                - Cracked screen
                - Scratched display
                - Dented/bent frame
                - Water damage indicators
                - Broken buttons
                - Damaged charging port
                - Camera lens scratches
                - Missing components
                - Corrosion
                - Burn marks
            """.trimIndent()
            
            try {
                val response = geminiClient.analyzeDeviceImage(image, prompt)
                response.fold(
                    onSuccess = { text ->
                        val cleanedJson = extractJson(text)
                        val damages = json.decodeFromString<List>(cleanedJson)
                        Result.success(damages)
                    },
                    onFailure = { e -> Result.failure(e) }
                )
            } catch (e: Exception) {
                Result.failure(e)
            }
        }
    
    private fun extractJson(text: String): String {
        // Remove markdown code blocks if present
        var cleaned = text.trim()
        if (cleaned.startsWith("```json")) {
            cleaned = cleaned.removePrefix("```json").removeSuffix("```").trim()
        } else if (cleaned.startsWith("```")) {
            cleaned = cleaned.removePrefix("```").removeSuffix("```").trim()
        }
        return cleaned
    }
}

@Serializable
data class DeviceRecognitionResult(

)

@Serializable
data class DamageReport(

    val severity: String,
    val location: String,
    val description: String,
    val repairability: String,
    val estimatedCost: String

### 6.3 Diagnostic Agent with Multi-Turn Conversation

**File: `ai/gemini/DiagnosticAgent.kt`**

```kotlin
package com.techrepairpro.app.ai.gemini

import com.google.ai.client.generativeai.Chat
import com.google.ai.client.generativeai.GenerativeModel
import com.google.ai.client.generativeai.type.content
import com.techrepairpro.app.BuildConfig
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.flow
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class DiagnosticAgent @Inject constructor() {
    
    private val model = GenerativeModel(
        modelName = "gemini-1.5-flash-latest",
        apiKey = BuildConfig.GEMINI_API_KEY
    )
    
    private var activeChat: Chat? = null
    
    /**
     * Start a diagnostic conversation session
     */
    fun startDiagnosticSession(
        deviceInfo: String,
        initialComplaint: String
    ): Chat {
        val systemPrompt = """
            You are an expert tech repair assistant specializing in Samsung, Apple, Google devices,
            and major home appliances. You're helping diagnose a repair issue.
            
            DEVICE: $deviceInfo
            INITIAL COMPLAINT: $initialComplaint
            
            Your role:
            - Ask clarifying questions to narrow down the root cause
            - Suggest diagnostic tests the technician can perform
            - Recommend specific repair procedures
            - Provide parts information when relevant
            - Keep responses concise and actionable
            
            Always respond in a professional, helpful manner. If you're unsure, admit it and
            suggest alternative diagnostic paths.
        """.trimIndent()
        
        activeChat = model.startChat(
            history = listOf(
                content(role = "user") { text(systemPrompt) },
                content(role = "model") { 
                    text("Understood. I'm ready to help diagnose this ${deviceInfo}. What specific symptoms are you observing?")
                }
            )
        )
        
        return activeChat!!
    }
    
    /**
     * Send message and get streaming response
     */
    suspend fun sendMessage(message: String): Flow = flow {
        activeChat?.let { chat ->
            val response = chat.sendMessageStream(message)
            response.collect { chunk ->
                emit(chunk.text ?: "")
            }
        } ?: run {
            emit("Error: No active diagnostic session. Please start a new session.")
        }
    }
    
    /**
     * End diagnostic session
     */
    fun endSession() {
        activeChat = null
    }
    
    /**
     * Get conversation history
     */
    fun getHistory(): List {
        return activeChat?.history ?: emptyList()
    }
}

import androidx.compose.ui.unit.dp
import androidx.compose.ui.viewinterop.AndroidView
import androidx.core.content.ContextCompat
import java.io.File
import java.text.SimpleDateFormat
import java.util.*
import kotlin.coroutines.resume
import kotlin.coroutines.suspendCoroutine

@Composable
fun CameraCapture(
    onImageCaptured: (Uri) -> Unit,
    onError: (Exception) -> Unit,
    modifier: Modifier = Modifier
) {
    val context = LocalContext.current
    val lifecycleOwner = LocalLifecycleOwner.current
    
    val cameraProviderFuture = remember { ProcessCameraProvider.getInstance(context) }
    val previewView = remember { PreviewView(context) }
    
    var imageCapture by remember { mutableStateOf(null) }
    var lensFacing by remember { mutableStateOf(CameraSelector.LENS_FACING_BACK) }
    var flashMode by remember { mutableStateOf(ImageCapture.FLASH_MODE_AUTO) }
    
    LaunchedEffect(lensFacing) {
        val cameraProvider = cameraProviderFuture.get()
        
        val preview = Preview.Builder().build().also {
            it.setSurfaceProvider(previewView.surfaceProvider)
        }
        
        imageCapture = ImageCapture.Builder()
            .setCaptureMode(ImageCapture.CAPTURE_MODE_MAXIMIZE_QUALITY)
            .setFlashMode(flashMode)
            .setTargetRotation(previewView.display.rotation)
            .build()
        
        val cameraSelector = CameraSelector.Builder()
            .requireLensFacing(lensFacing)
            .build()
        
        try {
            cameraProvider.unbindAll()
            cameraProvider.bindToLifecycle(
                lifecycleOwner,
                cameraSelector,
                preview,
                imageCapture
            )
        } catch (e: Exception) {
            onError(e)
        }
    }
    
    Box(modifier = modifier.fillMaxSize()) {
        AndroidView(
            factory = { previewView },
            modifier = Modifier.fillMaxSize()
        )
        
        // Camera controls overlay
        Column(
            modifier = Modifier
                .fillMaxSize()
                .padding(16.dp),
            verticalArrangement = Arrangement.SpaceBetween
        ) {
            // Top controls (flash toggle)
            Row(
                modifier = Modifier.fillMaxWidth(),
                horizontalArrangement = Arrangement.End
            ) {
                IconButton(
                    onClick = {
                        flashMode = when (flashMode) {
                            ImageCapture.FLASH_MODE_AUTO -> ImageCapture.FLASH_MODE_ON
                            ImageCapture.FLASH_MODE_ON -> ImageCapture.FLASH_MODE_OFF
                            else -> ImageCapture.FLASH_MODE_AUTO
                        }
                        imageCapture?.flashMode = flashMode
                    },
                    modifier = Modifier
                        .background(Color.Black.copy(alpha = 0.5f), CircleShape)
                ) {
                    Icon(
                        imageVector = when (flashMode) {
                            ImageCapture.FLASH_MODE_ON -> Icons.Default.FlipCameraAndroid
                            else -> Icons.Default.Camera
                        },
                        contentDescription = "Flash mode",
                        tint = Color.White
                    )
                }
            }
            
            // Bottom controls (capture & flip)
            Row(
                modifier = Modifier.fillMaxWidth(),
                horizontalArrangement = Arrangement.SpaceEvenly,
                verticalAlignment = Alignment.CenterVertically
            ) {
                // Flip camera
                IconButton(
                    onClick = {
                        lensFacing = if (lensFacing == CameraSelector.LENS_FACING_BACK) {
                            CameraSelector.LENS_FACING_FRONT
                        } else {
                            CameraSelector.LENS_FACING_BACK
                        }
                    },
                    modifier = Modifier
                        .size(60.dp)
                        .background(Color.Black.copy(alpha = 0.5f), CircleShape)
                ) {
                    Icon(
                        imageVector = Icons.Default.FlipCameraAndroid,
                        contentDescription = "Flip camera",
                        tint = Color.White,
                        modifier = Modifier.size(32.dp)
                    )
                }
                
                // Capture button
                FloatingActionButton(
                    onClick = {
                        val photoFile = File(
                            context.cacheDir,
                            SimpleDateFormat("yyyy-MM-dd-HH-mm-ss-SSS", Locale.US)
                                .format(System.currentTimeMillis()) + ".jpg"
                        )
                        
                        val outputOptions = ImageCapture.OutputFileOptions.Builder(photoFile).build()
                        
                        imageCapture?.takePicture(
                            outputOptions,
                            ContextCompat.getMainExecutor(context),
                            object : ImageCapture.OnImageSavedCallback {
                                override fun onImageSaved(output: ImageCapture.OutputFileResults) {
                                    onImageCaptured(Uri.fromFile(photoFile))
                                }
                                
                                override fun onError(exception: ImageCaptureException) {
                                    onError(exception)
                                }
                            }
                        )
                    },
                    modifier = Modifier.size(80.dp),
                    containerColor = MaterialTheme.colorScheme.primary
                ) {
                    Icon(
                        imageVector = Icons.Default.Camera,
                        contentDescription = "Take picture",
                        modifier = Modifier.size(40.dp)
                    )
                }
                
                // Placeholder for symmetry
                Spacer(modifier = Modifier.size(60.dp))
            }
        }

package com.techrepairpro.app.data.local.database

import androidx.room.TypeConverter
import com.google.gson.Gson
import com.google.gson.reflect.TypeToken
import java.util.Date

class Converters {
    
    private val gson = Gson()
    
    @TypeConverter
    fun fromTimestamp(value: Long?): Date? {
        return value?.let { Date(it) }
    }
    
    @TypeConverter
    fun dateToTimestamp(date: Date?): Long? {
        return date?.time
    }
    
    @TypeConverter
    fun fromStringList(value: String?): List? {
        val listType = object : TypeToken<List>() {}.type
        return gson.fromJson(value, listType)
    }
    
    @TypeConverter
    fun toStringList(list: List?): String? {
        return gson.toJson(list)
    }
    
    @TypeConverter
    fun fromMap(value: String?): Map? {
        val mapType = object : TypeToken<Map>() {}.type
        return gson.fromJson(value, mapType)
    }
    
    @TypeConverter
    fun toMap(map: Map?): String? {
        return gson.toJson(map)
    }
}

@Dao

    fun getAllRepairs(): Flow<List>
    
    @Query("SELECT * FROM repairs WHERE id = :repairId")
    fun getRepairById(repairId: String): Flow
    
    @Query("SELECT * FROM repairs WHERE customerId = :customerId ORDER BY createdAt DESC")
    fun getRepairsByCustomer(customerId: String): Flow<List>
    
    @Query("SELECT * FROM repairs WHERE technicianId = :technicianId AND status IN (:statuses)")
    fun getActiveRepairsByTechnician(
        technicianId: String,
        statuses: List
    ): Flow<List>
    
    @Query("SELECT * FROM repairs WHERE status = :status")
    fun getRepairsByStatus(status: String): Flow<List>
    
    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun insertRepair(repair: RepairEntity)
    
    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun insertAll(repairs: List)

### 10.4 Firebase Security Rules

**Firestore Security Rules:**

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Helper functions
    function isSignedIn() {
      return request.auth != null;
    }
    
    function isOwner(userId) {
      return request.auth.uid == userId;
    }
    
    function isTechnician() {
      return isSignedIn() && 
             get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'technician';
    }
    
    function isAdmin() {
      return isSignedIn() && 
             get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
    
    // Users collection
    match /users/{userId} {
      allow read: if isSignedIn();
      allow create: if isSignedIn();
      allow update: if isOwner(userId) || isAdmin();
      allow delete: if isAdmin();
    }
    
    // Devices collection
    match /devices/{deviceId} {
      allow read: if isSignedIn();
      allow create: if isSignedIn();
      allow update: if isOwner(resource.data.customerId) || isTechnician() || isAdmin();
      allow delete: if isOwner(resource.data.customerId) || isAdmin();
    }
    
    // Repairs collection
    match /repairs/{repairId} {
      allow read: if isSignedIn();
      allow create: if isSignedIn();
      allow update: if isOwner(resource.data.customerId) || isTechnician() || isAdmin();
      allow delete: if isAdmin();
    }
    
    // Parts inventory
    match /parts/{partId} {
      allow read: if isSignedIn();
      allow write: if isTechnician() || isAdmin();

### 13.1 Image Compression Utility

**File: `utils/ImageUtils.kt`**

```kotlin
package com.techrepairpro.app.utils

import android.content.Context
import android.graphics.Bitmap
import android.graphics.BitmapFactory
import android.graphics.Matrix
import android.media.ExifInterface
import android.net.Uri
import id.zelory.compressor.Compressor
import id.zelory.compressor.constraint.default
import id.zelory.compressor.constraint.destination
import id.zelory.compressor.constraint.quality
import id.zelory.compressor.constraint.resolution
import id.zelory.compressor.constraint.size
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import java.io.File
import java.io.FileOutputStream
import java.io.IOException

object ImageUtils {
    
    /**
     * Compress image to reduce file size while maintaining quality
     */
    suspend fun compressImage(
        context: Context,
        imageFile: File,
        maxSizeKB: Long = 1024, // 1 MB
        quality: Int = 80
    ): File = withContext(Dispatchers.IO) {
        Compressor.compress(context, imageFile) {
            quality(quality)
            size(maxSizeKB * 1024) // Convert KB to bytes
            destination(File(context.cacheDir, "compressed_${imageFile.name}"))
        }
    }
    
    /**
     * Resize bitmap to specific dimensions
     */
    fun resizeBitmap(
        bitmap: Bitmap,
        maxWidth: Int = 1080,
        maxHeight: Int = 1080
    ): Bitmap {
        val width = bitmap.width
        val height = bitmap.height

        if (width <= maxWidth && height <= maxHeight) return bitmap

        val ratio = minOf(maxWidth.toFloat() / width, maxHeight.toFloat() / height)
        val newWidth = (width * ratio).toInt()
        val newHeight = (height * ratio).toInt()

        return Bitmap.createScaledBitmap(bitmap, newWidth, newHeight, true)
    }

    /**
     * Fix EXIF rotation issues for camera/gallery images
     */
    fun fixImageRotation(context: Context, uri: Uri, bitmap: Bitmap): Bitmap {
        return try {
            val inputStream = context.contentResolver.openInputStream(uri) ?: return bitmap
            val tempFile = File.createTempFile("exif", ".jpg", context.cacheDir)

            tempFile.outputStream().use { output ->
                inputStream.copyTo(output)
            }

            val exif = ExifInterface(tempFile.absolutePath)
            val orientation = exif.getAttributeInt(
                ExifInterface.TAG_ORIENTATION,
                ExifInterface.ORIENTATION_NORMAL
            )

            val matrix = Matrix()
            when (orientation) {
                ExifInterface.ORIENTATION_ROTATE_90 -> matrix.postRotate(90f)
                ExifInterface.ORIENTATION_ROTATE_180 -> matrix.postRotate(180f)
                ExifInterface.ORIENTATION_ROTATE_270 -> matrix.postRotate(270f)
            }

            Bitmap.createBitmap(bitmap, 0, 0, bitmap.width, bitmap.height, matrix, true)
        } catch (e: Exception) {
            bitmap
        }
    }

    /**
     * Convert a content Uri into a local cache File (useful for compression/upload pipelines)
     */
    suspend fun uriToFile(context: Context, uri: Uri): File = withContext(Dispatchers.IO) {
        val inputStream = context.contentResolver.openInputStream(uri)
            ?: throw IOException("Unable to open input stream for uri: $uri")

        val file = File(context.cacheDir, "upload_${System.currentTimeMillis()}.jpg")
        FileOutputStream(file).use { output ->
            inputStream.use { input -> input.copyTo(output) }
        }
        file
    }
}

### 13.2 Network Optimization (OkHttp + Caching + Timeouts)

**File: `di/NetworkModule.kt`**

```kotlin
package com.techrepairpro.app.di

import android.content.Context
import com.techrepairpro.app.BuildConfig
import dagger.Module
import dagger.Provides
import dagger.hilt.InstallIn
import dagger.hilt.android.qualifiers.ApplicationContext
import dagger.hilt.components.SingletonComponent
import okhttp3.Cache
import okhttp3.OkHttpClient
import okhttp3.logging.HttpLoggingInterceptor
import java.io.File
import java.util.concurrent.TimeUnit
import javax.inject.Singleton

@Module
@InstallIn(SingletonComponent::class)
object NetworkModule {

    @Provides
    @Singleton
    fun provideOkHttpClient(@ApplicationContext context: Context): OkHttpClient {
        val cacheSize = 10L * 1024 * 1024 // 10 MB
        val cache = Cache(File(context.cacheDir, "http_cache"), cacheSize)

        return OkHttpClient.Builder()
            .cache(cache)
            .connectTimeout(15, TimeUnit.SECONDS)
            .readTimeout(30, TimeUnit.SECONDS)
            .writeTimeout(30, TimeUnit.SECONDS)
            .retryOnConnectionFailure(true)
            .addInterceptor(HttpLoggingInterceptor().apply {
                level = if (BuildConfig.DEBUG) HttpLoggingInterceptor.Level.BODY
                        else HttpLoggingInterceptor.Level.NONE
            })
            .addNetworkInterceptor { chain ->
                val response = chain.proceed(chain.request())
                response.newBuilder()
                    .header("Cache-Control", "public, max-age=60") // 1 minute
                    .build()
            }
            .build()
    }
}
```

## 14. FAQ & DEBUGGING

### 14.1 “BuildConfig.GEMINI_API_KEY is empty / unresolved”

**Cause:** `local.properties` not loaded or key name mismatch.

**Fix:**
- Ensure `local.properties` contains:
  - `GEMINI_API_KEY=...`
  - `STRIPE_KEY=...`
- Confirm your Gradle reads the exact same property names.

---

### 14.2 “google-services.json missing / Firebase not initializing”

**Fix checklist**
- `google-services.json` must be located at: `app/google-services.json`
- Ensure plugin is applied: `id("com.google.gms.google-services")`
- Sync Gradle and rebuild

---

### 14.3 Firestore: “Missing or insufficient permissions”

**Cause:** Security rules rejected the request.

**Fix**
- Confirm user is signed in: `request.auth != null`
- Verify ownership fields match your rules (e.g., `ownerId`, `customerId`)
- Use the Firebase Emulator Suite while iterating on rules (recommended)

---

### 14.4 CameraX preview black screen / crash

**Common causes**
- Missing permissions in manifest
- Runtime permission not requested
- Emulator without camera support

**Fix**
- Add permission: `android.permission.CAMERA`
- Request runtime permission before showing CameraX
- Test on a real device

---

### 14.5 Images rotated incorrectly after upload

**Cause:** EXIF orientation not handled.

**Fix:** Use `ImageUtils.fixImageRotation()` before compressing/uploading.

---

### 14.6 Stripe payment failing

**Typical causes**
- Live keys used in debug (or vice versa)
- Missing server-side PaymentIntent creation
- Network / config issues

**Fix**
- Keep Stripe secret key ONLY on backend (Cloud Functions)
- Client uses publishable key only
- Ensure backend returns a valid `client_secret`

### 14.7 Release build crashes but Debug works

**Cause:** R8/Proguard stripping classes (often via reflection/serialization).

**Fix**
- Add Proguard rules for:
  - Firebase
  - Retrofit converters (Moshi/Gson)
  - Kotlinx Serialization
  - Stripe SDK

**Quick triage**
- Temporarily set `isMinifyEnabled = false` for release to confirm R8 is the issue
- Re-enable and add targeted rules

---

### 14.8 “App not installing” / `INSTALL_FAILED_UPDATE_INCOMPATIBLE`

**Cause:** Different signing keys between installed build and new build.

**Fix**
- Uninstall the old app from the device
- Reinstall from the current build

---

### 14.9 Push notifications not received

**Checklist**
- Firebase Messaging enabled
- Device has Play Services
- Notification permission requested (Android 13+)
- Token is stored for the user in Firestore
- Backend sends to the correct token

---

### 14.10 Gemini errors / blocked content / empty responses

**Common causes**
- Safety filters triggered
- Prompt too long
- Network timeout

**Fix**
- Keep prompts structured and short
- Add retry/backoff on transient failures
- Log the model response and error payload in debug builds
