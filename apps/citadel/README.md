# Citadel

Citadel is the Matrix sovereign control surface.

## Scripts

- `npm run dev` - start on `3005` with Turbopack
- `npm run build` - production build
- `npm run start` - run built app
- `npm run lint` - lint source
- `npm run test` - run Vitest smoke checks

## Key Areas

- `src/app/` - routes and API handlers
- `src/components/` - interface components
- `src/lib/` - integration and utility logic
