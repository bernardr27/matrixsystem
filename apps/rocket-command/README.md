# Rocket Command

Rocket Command handles AGI pipeline execution and results surfaces.

## Scripts

- `npm run dev` - start on `4000` with Turbopack
- `npm run build` - production build
- `npm run start` - run built app
- `npm run lint` - lint source
- `npm run test` - run Vitest smoke checks

## Key Areas

- `src/app/` - pages and API endpoints
- `src/components/` - UI modules
- `src/lib/` - pipeline logic and shared helpers
