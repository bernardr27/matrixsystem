# Internal PR System (AI-Driven) 🚀

This directory contains autonomous code proposals generated by **Ralph** based on the PRDs in `docs/prd`.

## Workflow
1. **Requirements**: Add a `.md` PRD to `docs/prd`.
2. **Generation**: Ralph detects the PRD, implements the tasks in a localized/sandboxed fashion, and creates an `INTERNAL_PR_[NAME].md` here.
3. **Review**: You review the proposed code changes and build results.
4. **Approval**: To approve, change the `Status:` field in the PR document to `APPROVED`.
5. **Execution**: Ralph detects the `APPROVED` status and merges the changes into the production codebase.

## Directory Structure
- `pending/`: PRs awaiting review.
- `approved/`: PRs that have been signed off and are ready for merge.
- `merged/`: Archive of successfully applied PRs.
