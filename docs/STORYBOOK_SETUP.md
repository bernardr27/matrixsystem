# Storybook Setup

Storybook scaffold exists at `.storybook/` for cross-app component documentation.

## Start Commands (after installing Storybook deps)

```bash
npm run storybook
npm run storybook:build
```

## Scope

- Stories auto-discover from `apps/**/src/**/*.stories.*`
- Includes essentials and a11y addon placeholders

## Required Packages

- `@storybook/nextjs`
- `@storybook/addon-essentials`
- `@storybook/addon-a11y`

Install when you are ready to run Storybook in this workspace.
